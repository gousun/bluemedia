# blueapp - BlueMedia PC 端上位机

配合设备端固件使用：ESP32 旋钮设备把操作事件通过 BLE 发给本程序，本程序按当前模式模拟按键控制 PC。

## 快速开始（一键启动）

**双击 `一键启动.bat`** —— 首次运行自动装依赖，之后直接弹出图形控制台。

也可以手动运行：

```bash
pip install -r requirements.txt
python media_gui.py      # 图形界面（推荐）
python media_host.py     # 控制台版（无界面）
```

## 图形控制台（media_gui.py，pywebview + 毛玻璃界面）

- **外观**：深色玻璃拟态——动态渐变光斑背景、毛玻璃卡片、苹果曲线滑动动画；模式切换用分段控件滑动过渡（视图带模糊淡入）
- **连接状态**：右上角呼吸灯指示，断线自动重连
- **模式切换**：分段控件一键切换（等效长按旋钮），各模式按钮文案自动取自 `media_core.py` 的 `MODES` 表 `ui` 字段
- **系统音量条**：拖动直接设置 Windows 音量（pycaw），旋转旋钮/手动调节后实时同步回显
- **手动动作按钮**：播放/下一首等大按钮按当前模式映射触发，不用旋钮也能操作
- **事件日志**：设备每条事件带时间戳滑入显示（排查问题先看这里）

注意：设备只支持单连接，不要同时开 GUI 和控制台版（或多个实例）。

## 操作说明（设备端）

| 操作 | 音乐模式 | 抖音模式 | 自定义模式×2 |
|---|---|---|---|
| 旋钮右转/左转 | 音量+/音量-（系统音量，全局生效） | 同左 | 由映射决定（默认无） |
| 短按 | 播放/暂停 | 下一个视频 | 由映射决定 |
| 双击 | 下一首 | 暂停/播放（空格键） | 由映射决定 |
| 长按(≥0.7s) | 切换模式（全局，四模式循环） | 同左 | 同左 |

## 自定义模式（槽位 3/4）

GUI 分段控件最后两格（默认名 USER1/USER2），点视图里的 **⚙ 编辑名字与映射**：

- **模式名**：1~6 位英文/数字/符号，保存后自动同步到设备 OLED（受 OLED ASCII 字库限制，不支持中文）
- **手势映射**：短按/双击/旋转↑/旋转↓ 四个手势可分别映射为——常用快捷键（Ctrl+C、Alt+Tab、Win+D…）、媒体键、键盘任意键（点 🎯捕获 后按键录入）、鼠标按键（在光标位置点击）
- **持久化**：保存到 `blueapp/user_modes.json`，GUI 重启自动加载；设备重连时自动把名字重新同步给设备（设备侧名字存 RAM，重启后恢复默认名，由 GUI 自动补同步）
- 未烧录 4 模式固件时设备只有 1/2 两个模式，自定义槽位只在本地生效显示

**注意：**
- 音乐控制用系统媒体键，无需任何窗口前台
- 抖音模式模拟 ↑/↓ 方向键，**抖音窗口（PC 客户端或网页版）必须保持前台焦点**
- 抖音音量默认也用系统媒体键；如需用抖音客户端内置音量，把 `media_core.py` 中 MODES[2] 的 `rot_up/rot_down` 改为 ←/→ 键（文件内注释有说明）
- 短按生效有约 0.25s 延迟（双击判定窗口），属正常

## 功能扩展（加新模式）

1. 固件：`components/middlewares/app_state/app_state.h` 的 `media_mode_t` 加枚举、`app_state.c` 的 `mode_names[]` 加名字，重新编译烧录
2. 上位机：`media_core.py` 的 `MODES` 表加同编号条目（`rot_up/rot_down/single/double` 四个动作），GUI 会自动显示新模式

BLE 协议无需任何改动。

## 文件说明

| 文件 | 用途 |
|---|---|
| `一键启动.bat` | 一键启动 GUI（自动装依赖） |
| `media_gui.py` | 图形控制台宿主（pywebview + JS API 桥） |
| `web/index.html` | 毛玻璃界面（HTML/CSS/JS 单文件） |
| `media_core.py` | 共享核心：BLE 客户端/事件分发/模式映射表（含 `ui` 按钮文案） |
| `media_host.py` | 控制台版客户端 |
| `ble_test.py` | BLE 诊断：`python ble_test.py` 扫描、`--connect` 全链路测试 |
| `ble_listen.py` | BLE 事件监听（诊断用）：`python ble_listen.py` |
| `media_gui_error.log` | GUI 崩溃时自动生成的错误日志 |
