# BlueMedia —— BLE 媒体控制器改造计划

## 架构与分工

```
设备（ESP32 + 旋转编码器 + OLED）          PC 上位机（blueapp/，Python）
┌─────────────────────────────┐         ┌──────────────────────────────┐
│ 编码器 → 事件分类            │  BLE    │ 收事件 → 按当前模式映射按键   │
│  旋转/短按/双击/长按          │ ──────> │  音乐模式: 媒体键(全局)        │
│ 模式管理（长按切换）          │ FFE2通知 │  抖音模式: ↑↓切视频(需前台)    │
│ OLED: 模式/事件/音量条/BLE    │ <────── │ 回传 VOL:xx → OLED 音量条     │
└─────────────────────────────┘ FFE1写入 └──────────────────────────────┘
```

设备只上报**事件**，动作映射全部在上位机——以后加新功能/新模式只需两端各加一条映射，固件协议不变。

## 交互定义

| 操作 | 事件（FFE2 通知） | 音乐模式动作 | 抖音模式动作 |
|---|---|---|---|
| 旋钮右转 | `EV:ROT:+1` | 音量+（媒体键） | 音量+（媒体键） |
| 旋钮左转 | `EV:ROT:-1` | 音量- | 音量- |
| 短按 | `EV:KEY:S` | 下一曲 | 下一个视频（↓键） |
| 双击 | `EV:KEY:D` | 上一曲 | 上一个视频（↑键） |
| 长按(≥700ms，全局) | `EV:MODE:n` | — | — |

BLE 设备名改为 **BlueMedia**；FFE1 写命令：`VOL:<0-100>`（上位机回传系统音量，OLED 显示音量条）、`MODE:<1-n>`（上位机直接切模式）、`STATUS`（回报状态）。按键判定：长按≥700ms 即触发；双击间隔≤350ms。

## 固件改动

1. **bsp/encoder**：新增 `encoder_released()` 释放沿检测（与 pressed 配对，供按键状态机区分短按/双击/长按）
2. **middlewares/app_state 重写**：状态改为 模式/最近事件/音量/BLE连接；提供模式名表（"MUSIC"/"DOUYIN"）；**原风扇/强启/定时逻辑全部移除**
3. **middlewares/ble_svc 改造**：设备名 BlueMedia；新增 `ble_svc_notify_event()` 事件通知；FFE1 解析 VOL/MODE/STATUS
4. **main.c 重写**：按键状态机（IDLE→按下→长按即时触发 / 释放后350ms内二次按下=双击）→ 事件直接 BLE 通知 + 更新显示状态；删除风扇控制/DHT/ctrl 任务
5. **ui.c 重写**：启动动画（"BlueMedia" + 音符图标 + 进度条）；状态页：MODE:MUSIC/DOUYIN、最近事件（VOL+/VOL-/NEXT/PREV/MODE）、音量进度条、BLE 状态
6. **LED** = BLE 连接指示；**fan/dht11 组件源码保留在仓库但不参与应用**（不被引用，链接时被裁剪）
7. 扩展接口：固件 `MEDIA_MODE_COUNT` 枚举 + 模式名表加一项即新增模式

## 上位机改动（blueapp/）

- 新增 `media_host.py`（替代 fan_cli.py，将删除旧文件）：
  - bleak 连接 BlueMedia、订阅 FFE2、写 FFE1
  - **pynput** 模拟按键：音乐模式用系统媒体键（media_volume_up/down、media_next/previous，全局生效）；抖音模式用方向键（抖音窗口需为前台焦点）
  - **pycaw**（可选依赖）读取 Windows 系统音量，每次调音量后回传 `VOL:xx` 给设备显示
  - 模式映射表 `MODES = {1: {...}, 2: {...}}` 顶部集中配置，注释说明抖音音量可改为 ←→ 内置音量；**以后扩展=加一个模式条目**
- requirements.txt：bleak、pynput、pycaw、comtypes；blueapp/README.md 重写
- bluefan_esp/README.md 重写为媒体控制器文档（协议表/模式扩展指南/构建说明）

## 验证

1. `idf.py build` 编译通过（手工环境批处理，与之前相同）
2. `media_host.py` py_compile 语法检查
3. 真机联调：烧录后 PC 运行 `python media_host.py`，旋转/按键验证音乐控制；切到抖音模式并保持抖音窗口前台验证切视频

## 说明

- 抖音的 ↑↓ 切视频、←→ 音量按键映射写成可配置，不同版本（PC 客户端/网页版）如有差异改 MODES 表即可
- 设备不解析具体动作，音量显示依赖上位机回报（pycaw 未装时音量条显示 `--`，其余功能不受影响）
